Each tracker is a register of the Chinese investment projects reported in one country's own press: every report is quoted and linked, and each project is followed from the first promise to a plant, a dormant plan or an exit. The trackers share one method, so the countries can be compared.

One project, one site

A project is a Chinese, Hong Kong or Macau investor, or a Chinese-owned brand, tied to a site or a target in the country. Construction contracts and Chinese loans are recorded but not counted as investment; Taiwanese firms are excluded.

Every report quoted and linked

Each press report is a claim with the sentence as published and a link to the article. The Hungarian and Kazakh trackers add an English translation to every quote.

Promises followed over time

Projects are realised, live promises, dormant promises (no report for a set number of years) or failed. The same rules in every country make the comparisons possible.
